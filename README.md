Тесты модели на mstest. Кажется все требования, в том числе дополнительные реализованы. Хотелось ещё сделать селект по клику на области отрисовки, но на это ещё какое-то время ушло бы. В процессе использовал ChatGpt для справки по WPF в том числе для выбора способа отрисовки фигур (Изначально рассматривал вариант отрисовки через DrawingContext, но потом остановился на более простом способе Shapes на Canvas). Так же использовал сгенерированный код для инициализации DI контейнера.
